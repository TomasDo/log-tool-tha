# Oberon 日志时间轴

供售后人员在本地检查 Oberon（THA）运行日志的网页工具。导入文件后可查看手术、日志、一级页面、二级任务、采集操作和设备六轨时间轴，并从方案汇总或异常跳转到原文证据。

## 启动

Python 3.10+，运行只使用标准库，无需安装依赖或构建前端：

```bash
python3 -m app.main
```

浏览器打开 http://127.0.0.1:8765 。默认监听 `0.0.0.0:8765`；本机使用可指定 `python3 -m app.main 127.0.0.1:8765`。

修改 Python 或前端代码后重启服务；仅修改规则文档后点「重新加载规则」即可。可用 `LOG_TOOL_DATA_DIR=/abs/path` 指定独立数据目录。

## 售后排查

1. 「导入日志」支持多选。逐文件显示导入失败原因；Titan、空文件和全零文件拒绝分析。内容相同的文件复用已有副本并记录别名，同名不同内容分别保留。
2. 一次查看一个文件。同一次进程可加载多个方案；同 UUID 多次启动合为一张汇总卡，轨道保留实际区间。无启动行的 Oberon 片段可分析，无 UUID 不猜测方案。
3. 默认显示关键操作、异常和普通业务事件。「显示噪声」查看连续力矩、关节角和原始 NDI 位姿，「显示全部」查看未映射内容。原文搜索覆盖整个文件，包括隐藏行和窗口外的行。
4. 「上一异常／下一异常」循环定位。点击轨道或汇总后，终端显示目标行及附近上下文；展开证据栏查看原文、方案、会话、目标来源、数值和阈值。
5. 方案汇总保留「完成／未做」：完成表示找到所配置的日志证据。未开始手术的方案不评必要步骤。清空、撤销、回退独立记录，不抹除曾执行过的操作，也不代表旧结果仍然有效。
6. RAS 和 APP 分开比较，目标只取同一方案、同一会话、同坐标系的最近有效记录。全零占位不当实测；缺目标不算 Δ，深度仅显示 mm 原值。
7. 缩放使用 −／+／适应窗口；拖动和滚轮平移。蓝色表示当前选中行和播放头，红色表示异常。终端分割条只调整终端高度；窗口较矮时可在轨道标签区或滚动条纵向滚动，查看三级和设备轨道。大于 3 万行时终端窗口化，点击、搜索可加载远处证据并保留缩放。手动滚动终端后，点击异常、汇总或轨道会重新显示目标原文。

未知产品文本只供原文查看，不生成手术结论。记录结束不等于软件正常退出，日志缺失也不能单独解释故障原因。

## 规则和阈值

`docs/oberon-log-spec.md` 是分类、事件ID、轨道、必要步骤证据和阈值的配置入口。中文显示名可以修改，业务识别依赖稳定事件ID。

默认排查阈值：标定／配准误差严格大于 1 mm 标红；角度偏差严格大于 1° 提醒、大于 2° 显示“偏差超阈值”。源码中的 RAS/APP realtime 记录是定位前、停止或切页时的过程位姿快照，保留数值、偏差和重点标记，不单凭其判定故障或最终杯验证不合格。误差在表格「阈值」列配置，角度在 `threshold:angle_key` / `threshold:angle_anomaly` 配置。

人工请求重启后的首次 KUKA 断开、未记录手术开始的断开/急停状态，以及有明确替代模块监听证据的 MXIO 回退流程保留为可见提醒；未确认的术中断开、独立连接失败与保护停止仍标红。替代模块监听不等于设备已连接或示教可用。NaN、无穷大、负误差等无效数值单独标异常，不充当有效完成证据；E/C 始终标红。

E/C 保持异常级别，同时保留业务类型；W 警告默认显示，即使命中原始转储规则也不折叠。`set` 设置、`switch` 切换、工具类型/侧别编号、坐标系切换和示教硬/软开关操作默认显示，且不被通用指令噪声规则隐藏。已有页面/步骤分类仍优先保留。重力补偿、定线/定点、移动、示教停止、制动测试等请求、机器人停止状态及脚踏界面反馈默认显示；正常切页待机、标定/配准矩阵、程序路径、网卡地址和偏移配置回显也保留，并注明它们不等于执行成功或实际采用的配置。高频原始转储默认折叠，设备故障、运动失败、标记偏移停止、配准清空／撤销等不被普通噪声吞掉。

## 文件和日期

支持 UTF-8/BOM、CRLF/LF、`+0800` / `+08:00` 时区以及多行崩溃堆栈。原始行号和文本保留；一次崩溃计一个异常事件。

日期优先取 `tha_log_file_YYYY-MM-DD.txt` 文件名。医院改名文件使用来源文件时间（浏览器传 `lastModified`，路径导入取源文件 mtime），来源不可用时显示未知，不使用导入副本的创建时间。

医院日志、`data/`、`samples/` 不提交到 Git。删除只影响导入副本，不修改原始文件。

## 本地 API

- `GET /api/logs`、`POST /api/logs`（multipart，多文件；可附 `last_modified` JSON，文件名到毫秒时间的映射）
- `POST /api/logs/import-path`：`{"path":"/abs/file.txt"}` 或 `{"paths":[...]}`
- `GET /api/logs/{id}/timeline?show_noise=0&show_all=0&center=1&window=12000`
- 全文搜索：同一 timeline API 附 `q=关键词&after=行号&direction=next`（或 `prev`），返回 `search.total` / `search.line`
- `DELETE /api/logs/{id}`、`GET /api/spec`、`POST /api/spec/reload`

兼容原 API 和 `steps[].ok`；新增 `file_quality`、事件ID、会话／方案上下文、数值和步骤证据。`events` 最多返回 5 万条，`truncated` 提示截断；计数和轨道仍覆盖完整分析。文件列表按当前规则重算计数。

## 验证

```bash
python3 -B -m unittest discover -v
node --check web/app.js
```

运行不需要 Node；上述 Node 命令仅用于开发时检查 JavaScript。测试不包含医院日志。现场样本回归结果见 `docs/validation-2026-10-28.md`。噪声、未映射和异常识别复核分别见 `docs/noise-review-2026-10-28.md`、`docs/unmapped-review-2026-10-28.md`、`docs/anomaly-review-2026-10-28.md`。

源码补充识别自定义示教模块版本查询、模块版本、遮罩处理、设备准备指令上下文和三类示教保护告警。模块版本与 Oberon 软件版本分别记录；保护处理不代表机器人动作已经完成。实际未知消息仍保留未映射身份，不用泛化规则人为清零。

浏览器验收与界面修正见 `docs/browser-acceptance-2026-10-28.md`，覆盖正常操作、异常循环跳转、原文/堆栈证据、隐藏行及大文件窗口。
