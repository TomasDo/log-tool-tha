## 验收中发现并修正的问题

1. 当前选中行原本用红色背景/边条，正常操作也显得像异常。选中背景、主时间轴播放头和概览播放头改为蓝色，异常原文仍为红色；启动行保留其绿色身份边条。
2. 手动滚动后“跟随播放头”关闭，主动点击异常/汇总/轨道可能只更新详情而不显示目标行。主动跳转现在恢复跟随，并把原文带入可视区；噪声过滤与全部过滤的跟随行为一致。
3. 展开/收起详情会改变画布显示高度，原图被拉伸且点击位置可能与图形错位。增加尺寸观察，重绘画布并更新虚拟终端；验证像素高度始终匹配 CSS 高度乘设备像素比。
4. 较矮窗口会裁掉三级、设备轨道。轨道区保持六轨所需高度并支持纵向滚动；在 1280×720 的默认验收视口中确认下方轨道可访问、可点击。
5. 切换文件后可能残留上一文件的轨道悬停说明。加载、重绘和鼠标离开时清除旧提示，切换文件同时恢复轨道区顶部。
