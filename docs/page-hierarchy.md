# Oberon 时间轴层级

事件ID、中文显示名、轨道及父页面统一配置在 `oberon-log-spec.md`，本文件只解释模型。

| 轨道 | 内容 |
| --- | --- |
| 手术 | UUID 对应的实际日志区间；同 UUID 同色，跨会话仍共用一张汇总卡 |
| 日志 | 完整文件行号上的重点/异常刻度；多行崩溃只画一个异常刻度 |
| 一级 | 方案预览、设备准备、髋导航、可选股骨导航、术后 |
| 二级 | 髋骨/股骨导航页内任务；仅在相应父页面内有效 |
| 三级 | 稀疏/精配准/验证采集，以及清空、撤销、解锁清空等操作事件 |
| 设备 | 设备准备步骤、连接及故障恢复、急停、示教、脚踏、随动、器械与停止原因 |

横轴为原始日志行号。缩放由按钮控制，拖动/滚轮平移。登录、方案管理不占一级轨道。

启动建立软件会话；UUID 加载切分方案。没有启动行的片段可建立标有起点缺失的会话；无 UUID 的区间显示灰色。一次启动中切换两个方案必须分开归属。再次加载方案会重置页面与目标状态，不跨区间沿用数值。

同 UUID 的多个区间共用颜色及汇总卡；中间的其他方案和无方案区间不会被覆盖。标签使用杯型、侧别和顺序号，不使用患者姓名。启动版本绑定实际会话。

“完成/未做”由规则中的必要步骤证据判定，点击命中项可定位原文；未开始手术不评步骤。清空/撤销保留独立历史，已清除结果不作为当前误差展示。

角度快照只归属实际所在区间，不向后多借 12 行。悬停显示同坐标系的目标、实测、偏差、单位和目标来源；详情栏可查看单条快照。日志没有明确目标时不推导差值。不能确定归属的事件仅保留原文证据。

过程位姿快照保留 1°/2° 偏差阈值提示，事件不因过程角度偏大自动标红；E/C 和无效数值仍为异常。`metrics[].threshold_level` 表示偏差阈值级别，`assessment=process_snapshot` 说明数值来源。最新误差或位姿无效时，不再把旧数值展示成当前有效结果，原始记录和曾执行过的步骤证据仍可查看。
